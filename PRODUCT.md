# CalcNoir

## Register

product

## Users

Students learning numerical methods on Android, often during a class or while working on homework. They need to enter their own problem, obtain an honest numerical answer, and inspect the reasoning when they choose. Existing project and user context establish this audience; this is an app, not a marketing website.

## Product Purpose

Solve the six existing numerical methods, explain recorded calculations offline, and organize reusable saved problems on the device. The current user explicitly requests the name CalcNoir throughout the app, a black-and-white theme, getting started, separate method pages with Back, and local saved-problem CRUD. Additional formulas and a live AI API remain later work.

## Brand Personality

Precise, quiet, approachable. Use plain task labels, familiar controls and short guidance. The user explicitly rejects overwhelming screens and generic AI styling.

## Anti-references

The previous all-in-one solver with method selection, formulas, editor, steps, graph, table and notebook actions on one scroll. Avoid marketing heroes, decorative metric cards, gradients, colored accents, excessive onboarding and a full Notion clone.

## Design Principles

- One task per screen: choose a method, enter a problem, then view its answer.
- Explanation is optional depth: steps, graph, table and comparison open deliberately.
- Familiar Back behavior preserves the input screen beneath the result.
- Notebook organization stays in the notebook: titles, notes, tags, pinning, search and duplication support actual numerical work.
- Preserve validated local data and report numerical limits honestly.

## Accessibility & Inclusion

Target WCAG AA contrast, scalable native text, labeled controls, visible selected/disabled states, at least 48 dp touch targets and layouts that tolerate large text. Graphs use line styles, markers and labels rather than color alone. Native device verification is required; unrun TalkBack/physical-device checks must be disclosed.
