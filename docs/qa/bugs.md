# QA findings — 2026-11-13

Scope: the offline Android app in `Numerical/calcnoir`. Severity describes the reproduced impact. Source regression results below do not substitute for packaged-device checks; see [report](report.md) for their final status.

| ID | Severity | Reproduction and expected behavior | Repair and evidence |
| --- | --- | --- | --- |
| NUM-01 | High correctness | Newton on `cos(1e-20*x)-1`, first guess 1, reported an exact root at 1 because cosine rounded to 1. It must report precision loss instead. | Reject cosine saturation while retaining ordinary `cos(0)` and constant π cases; `qa-numerics.test.ts`. |
| NUM-02 | High correctness | Positive `1e20*x^2+1` and scaled log-squared equations could converge with residuals ≥1. A recursively inflated residual scale hid the error. | Add/subtract scales use current operands, preserving meaningful cancellation and uniform scaling; scaled rootless and tiny Secant regressions. |
| NUM-03 | High correctness | Divided differences on `(0,0),(1e-150,1),(2e-150,4)`, target `1e-200`, returned a negative value and a contradictory table. `(0,0),(1,1),(2,4)` at `1e-20` falsely returned zero. | Detect absorbed coordinates, subnormal/zero-underflow products, amplified cancellation and table disagreement. Ordinary non-node zeros and small nonzero answers have regression coverage. |
| NUM-04 | Medium | Supported constant notation `2πx` did not normalize into a usable expression. | Delimit the normalized `pi` constant; numerical regression coverage. |
| DATA-01 | Medium | Load an unsupported, corrupt or partially invalid notebook, then Save/Remove. The old implementation silently replaced its contents. | Repository rejects mutations, preserves original serialized bytes, exposes read-only recovery warning; UI blocks Save/Remove while allowing usable recovered problems to open/share. `qa-notebook.test.ts` and real-App `qa-flows.test.tsx`. |
| UI-01 | Medium | Delay theme loading and toggle before it completes; the old stored choice could overwrite the newer one. Two batched toggles lost a change, and reversed writes could persist an old choice. | Selection revision and serialized writes; controlled async regression tests. |
| UI-02 | Medium | Check practice answer 1.5, then edit to 9; success feedback remained visible. | Clear correctness and feedback whenever the answer changes; regression test. |
| UI-03 | Medium | In Bisection enter incomplete bracket `-`, switch to Newton, then Calculate. An invisible bracket field blocked the valid visible inputs. | Parse required fields for the active method; preserve raw drafts and finite unused settings. Three root-method direction regressions. |
| SEC-01 | Medium | Append an unsigned asset to a copied signed AAB. The previous verifier accepted it and marked the manifest verified. | Fully consume each JAR entry and require one matching leaf signer for every payload; reject duplicate names and stale success. Eight real-JDK fixture tests cover legitimate archives, tampering, nested metadata and mismatched certificates. |
| DEV-01 | Medium | Launch the debug app without Metro: Android opens a red “Unable to load script” screen. Cold transforms also competed with emulator boot. | Verify local Metro and prepare its Android bundle before emulator startup. Missing Metro stops with an actionable command. Loopback-only default listener, streamed size/time bounds and redirect rejection. Launch-flow and preflight tests. |
| DEP-01 | Moderate advisory | TypeScript ESLint pulled vulnerable `minimatch` 10.2.6. | Scoped override to patched 11.0.1; full source checks pass. Full audit falls from 15 to 9 findings, all low. See [dependency disposition](dependencies.md). |

Numeric failures now explain precision limits rather than returning a misleading success. This is bounded double-precision software, not an arbitrary-precision symbolic solver. Notebook recovery intentionally preserves unknown data; an automatic reset/migration feature was not added.
