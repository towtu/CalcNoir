## Security check

Checked bounded expression allowlists/evaluation, typed validated storage boundaries, fixed private SQLite path, bound SQL values, transaction rollback, native worker lifecycle, legacy/corrupt-data preservation, capacity protection, read-only mutation guards, error redaction, no notebook logging, native text rendering, explicit system sharing, ignored signing inputs and complete AAB payload signature coverage. No account, server, uploads, payments, WebView or live AI service exists in this phase, so server/auth/CSRF/webhook controls do not apply.

Limits: double-precision calculations and sampled plots are not arbitrary precision or continuity proofs. Automatic corrupt-notebook recovery/reset is not implemented. Actual TalkBack speech, physical phones, other Android API levels and iOS are not verified. SQLite is Android-only; iOS retains AsyncStorage. These are test-certificate builds, not Play upload builds. Additional formulas await the user. The live AI API remains the final planned feature, requiring a server-held provider key and bounded authenticated requests.
